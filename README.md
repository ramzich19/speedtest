# speedtest

Скрипт для замера скорости интернета. Делает 10 запросов подряд к указанному адресу, ждет полной загрузки каждого и считает среднее время запроса, объем скачанного и скорость.

## Требования

Python 3.7+, сторонние библиотеки не нужны.

## Запуск

```
git clone https://github.com/ramzich19/speedtest.git
cd speedtest
python speedtest.py <url>
```

Пример:

```
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Вывод:

```
#1: 4.13 МБ за 0.842 с
#2: 4.13 МБ за 0.795 с
...
#10: 4.13 МБ за 0.811 с

Успешных запросов: 10 из 10
Среднее время запроса: 0.813 с
Скачано всего: 41.30 МБ
Скорость: 5.08 МБ/с (40.64 Мбит/с)
```

Дополнительные параметры:

- `-n` - количество запросов (по умолчанию 10)
- `-t` - таймаут одного запроса в секундах (по умолчанию 30)

Скорость считается как общий объем, деленный на суммарное время всех запросов. МБ здесь это мегабайты (1024 * 1024 байт), в скобках та же скорость в мегабитах.
